# BullPrint Net — Brand Kit (v1)

Companion to the landing-page handoff. Design reference: `BullPrint Net Brand Kit.dc.html` (open in browser). Recreate/consume as noted — the SVGs in `assets/` are real, usable vector masters.

## Architecture
- **Master brand: BULLPRINT NET** (bullprintnet.com) — owns the circuit-bull badge, wordmarks, BN monogram.
- **Sub-brand: bullnet.ai — compute** — same tokens/type, no separate mark. Always subordinate; footer credit "A BullPrint Net platform." Domain always lowercase: bullnet.ai.
- Monochrome only: #07060C (void) + #F3F1FA (fg), grays #A7A3BC / #6E6A83, panel steps #0C0A15 / #12101C / #1A1727 / #221E31. No color, no gradients, no glow.

## Marks
1. **Circuit-bull badge** (`bullprintnetlogo.jpg`, raster 400px) — primary identity. Black backgrounds only. Min 48px. ⚠ Request ≥1200px master before any print/merch use.
2. **Vector ring badge** (`ring-badge-on-dark.svg` / `-on-light.svg`) — engraving/embroidery/one-color-print-safe seal; the only badge allowed on light surfaces. Ring text: BULLPRINT (top arc), — NET — (bottom arc), BN + circuit nodes center. Outer ring 2.5 stroke, inner 1.
3. **BN monogram** (`bn-monogram-on-dark/light.svg`) — tiles/app surfaces, 24–48px. Node dot below.
4. **B glyph** (`b-glyph-on-dark.svg`) — ≤32px, favicons 16/32. Single circuit node top-right.

## Wordmarks (type lockups — set live, don't rasterize)
- A Horizontal: "BULLPRINT NET", Inter 600, track +0.04em.
- B Stacked: BULLPRINT over NET; NET at #A7A3BC, track +0.35em.
- C Terminal: "BULLPRINT_NET://" JetBrains Mono 500, track +0.12em — dev surfaces only.
- D Tagline rail: "3D PRINT • COMPUTE • NETWORK", JetBrains Mono, track +0.3em, never bold.
- bullnet.ai lockups: "BULLNET" white + ".AI" #6E6A83; descriptor variant adds "// COMPUTE" mono line.

## Rules
- Clear space: badge = ⅓ diameter all sides; wordmarks = cap height.
- Don'ts: no color/tints, no shadows/glow, no raster badge on light, no stretch/rotate/outline/retrack.
- SVG masters use live Inter via @import — **convert text to outlines** before shipping to engravers/print vendors (Illustrator: Type → Create Outlines).

## Type
- Inter 500–600 — display + wordmarks (display track −0.02/−0.03em).
- JetBrains Mono 400–600 — labels, tagline, domains, specs; uppercase, track +0.12–0.32em, never bold.
